# Documentação Técnica do Projeto

## Visão Geral do Sistema

O projeto é uma aplicação web que permite ao usuário calcular volumes de árvores em diferentes regiões, utilizando dados fornecidos pelo usuário. O sistema suporta dois tipos principais de cálculos: QuickVol e GetStats.

## Tecnologias

- **Frontend**: React, Vite
- **Backend**: Node.js (não explicitamente mencionado no código)
- **Estilização**: CSS
- **Utilitários**: XLSX para manipulação de arquivos Excel
